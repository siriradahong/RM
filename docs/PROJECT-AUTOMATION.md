# รับโครงการ → แจกงาน → ปฏิทิน

ปรับตามไฟล์ e-office ต้นแบบ โดยใช้ข้อมูลจริงในฐานข้อมูล และรักษาการจำกัดสิทธิ์ตามบทบาท

## การใช้งาน

1. หัวหน้าฝ่าย หัวหน้าศูนย์ ผู้รับมอบอำนาจ หรือผู้บริหาร เปิด **ติดตามโครงการ → รับโครงการและแจกงาน**
2. เลือกฝ่าย/งาน วางข้อความ หรือลาก PDF, DOCX, XLSX หรือรูปเอกสารขนาดไม่เกิน 20 MB เพื่ออ่านข้อความในเครื่อง
3. ระบบเตรียมชื่อโครงการ วันสิ้นสุด และรายการงานจากบรรทัดมอบหมายที่ระบุชัดเจน จับชื่อเต็มกับบัญชีที่เปิดใช้งานในขอบเขต หากไม่พบหรือกำกวมจะเว้นไว้
4. ตรวจหรือเติมเฉพาะข้อมูลที่ขาด แล้วกด **ยืนยันโครงการและแจกงาน** ครั้งเดียว ระบบบันทึกโครงการ งาน ผู้รับผิดชอบ และการแจ้งเตือนในธุรกรรมเดียวกัน
5. เมนู **ปฏิทิน** แสดงงานเหล่านี้ทันที กดวันที่เพื่อดูรายการและเปิดโครงการต้นทางได้ ไม่ต้องสร้างนัดหมายซ้ำ

ตัวอย่างข้อความที่อ่านได้แน่นอน (ใช้ชื่อเต็มตรงกับบัญชีจริง):

```text
ชื่อโครงการ: คัดกรองสุขภาพชุมชน
สิ้นสุดโครงการ: 31/10/2569
- เตรียมอุปกรณ์ | ชื่อ-นามสกุลผู้รับผิดชอบ | 25/10/2569
- ลงพื้นที่ | ชื่อ-นามสกุลผู้รับผิดชอบ | 26/10/2569 | 09:00–11:00
```

## ข้อมูลและข้อจำกัด

- อ่านด้วยกติกาในเครื่อง ไม่ใช้ AI ภายนอกและไม่รับประกันว่าจะเข้าใจเอกสารทุกรูปแบบ บรรทัดงาน/ผู้รับผิดชอบ/วันที่ที่ไม่ชัดต้องตรวจเองก่อนมอบหมาย ไม่เลือกบุคลากรแบบสุ่มหรือสมมติวัน
- การอ่านไฟล์ขั้นนี้ใช้ไฟล์ชั่วคราวและลบหลังอ่าน เก็บ **ข้อความที่อ่านได้และข้อความอ้างอิงของแต่ละงาน** เป็นต้นฉบับโครงการ ไม่ฝากไฟล์ต้นฉบับลงคลังโดยอัตโนมัติ
- PDF สแกนและรูปเอกสารต้องมีโมเดล OCR ภาษาไทยและอังกฤษในเครื่องตามขั้นตอนเดิม `.doc`/`.xls` ต้องแปลงเป็น `.docx`/`.xlsx`
- การวิเคราะห์ยังไม่ออกคำสั่งงาน จนหัวหน้ากดยืนยัน หากไม่มีรายการงานสามารถบันทึกโครงการก่อนและมอบหมายเพิ่มเติมภายหลัง
- กดยืนยันซ้ำหลังการตอบกลับสะดุดไม่สร้างโครงการ/งานซ้ำ ใช้รหัสการส่งเดียวกัน
- วันงานต้องไม่เกินวันสิ้นสุดโครงการ เวลาเริ่ม/สิ้นสุดต้องครบและเรียงถูกต้อง ผู้รับงานต้องเปิดใช้งาน อยู่ในฝ่าย และอยู่ในงาน/ศูนย์ที่เลือกหรือหน่วยย่อยของงานนั้น
- ปฏิทินอ่านจาก `project_tasks` โดยตรง เมื่ออนุมัติเลื่อนกำหนดหรือเปลี่ยนสถานะจึงแสดงค่าปัจจุบัน ไม่มีสำเนานัดหมายที่ต้องไล่แก้ตาม งานไม่มีเวลาแสดงเป็นกำหนดส่งทั้งวันและไม่ถูกนับว่าเวลาชน
- เตือนสีเหลืองเมื่อช่วงเวลาทับซ้อนจริงและมีผู้รับผิดชอบ/ผู้เข้าร่วมคนเดียวกัน งานเสร็จแล้วไม่สร้างคำเตือนเวลาชน
- เจ้าหน้าที่เห็นเฉพาะงานของตน หัวหน้าเห็นตามขอบเขต ผู้บริหารเห็นภาพรวม แอดมินล้วนไม่มีสิทธิ์อ่านงานของบุคลากรเพิ่ม ต้นฉบับโครงการทั้งหมดแสดงเฉพาะผู้จัดการโครงการ
- การแจ้งเตือนในเว็บทำงานทันที ส่วน LINE ใช้การเชื่อมต่อและค่ากลางเดิม ไม่ถือว่าการเพิ่มงานในเว็บเป็นการส่ง LINE สำเร็จ

## หน้าจอ

แถบข้างสีเขียวตามตัวอย่าง มีทางเข้าโดยตรง: รายงานจาก LINE, เขียนรายงาน, แดชบอร์ดของฉัน, ติดตามโครงการ, ปฏิทิน, แดชบอร์ดหน่วยงาน/สำนักตามสิทธิ์ และเมนูเดิมสำหรับคลัง รายงานสรุป พื้นที่งาน และดูแลระบบ มือถือใช้ปุ่มเปิด–ปิดเมนู

## ตรวจสอบ

ใช้ฐานข้อมูลชั่วคราวแยกจากข้อมูลใช้งานจริง: ทดสอบสิทธิ์ การอ่าน DOCX จริง การไม่เดาชื่อ/วันที่ การย้อนกลับทั้งธุรกรรมเมื่อมีงานผิด การส่งซ้ำ ปฏิทินตามสิทธิ์ เวลาชน และการเลื่อนกำหนด รวมถึงทดสอบเบราว์เซอร์บนคอมพิวเตอร์/มือถือด้วย `npm run test:projects` ไม่ seed โครงการสมมติลงฐานข้อมูลจริง

Migration 12 เพิ่มข้อความต้นฉบับ รหัสป้องกันส่งซ้ำ และเวลางานโดยไม่แก้ข้อมูลคอลัมน์เดิม
