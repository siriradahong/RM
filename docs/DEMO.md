# ลองระบบด้วยข้อมูลสาธิต

ข้อมูลทั้งหมดที่ขึ้นต้น `[สาธิต]` เป็นข้อมูลสมมติ ตัวเลขพื้นที่และผู้ปฏิบัติงานไม่ใช่ผลการปฏิบัติงานหรือข้อมูลบุคคลจริง ตัวเลขแดชบอร์ดรวมทั้งข้อมูลเดิมกับรายการสาธิต และหน้าเว็บแสดงป้ายกำกับ

ชุดข้อมูลเพิ่มในฐานข้อมูลเครื่องนี้ด้วย `npm run demo:seed` เท่านั้น มีสำรองก่อนเพิ่มและไม่แก้ข้อมูลเดิม เรียกซ้ำจะไม่เพิ่มซ้ำ ไม่เปลี่ยนรหัสผ่าน และไม่รีเซ็ตรายการที่ลองแก้ไปแล้ว

## เข้าสู่ระบบ

เปิด `http://localhost:3001` บัญชีและรหัสผ่านอยู่ใน `data/demo/accounts.md` ถ้ากำหนด DATA_DIR ไว้ต่างจากค่าเริ่มต้น ให้ดูไฟล์ demo/accounts.md ภายในโฟลเดอร์นั้น รหัสผ่านสร้างแบบสุ่มสำหรับเครื่องนี้ ไม่อยู่ใน GitHub

| บัญชีที่แนะนำ                 | บทบาท                                       | ลองทำอะไร                                                                      |
| ----------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------ |
| `demo.executive`              | ผู้บริหาร                                   | ภาพรวมสำนัก กรองเดือน/ฝ่าย เปิดรายละเอียดงานและหลักฐาน                         |
| `demo.staff.health-promotion` | พนักงานฝ่ายส่งเสริมสุขภาพ                   | งานของตัวเอง นำเข้าไฟล์ สร้างรายงาน เพิ่มประเภทงาน เชื่อมหลักฐาน               |
| `demo.head`                   | หัวหน้าฝ่ายที่ได้รับมอบหลายขอบเขตในชุดสาธิต | ตรวจรายงานของทุกฝ่ายสาธิต แก้รายการรอตรวจ และดูยอดหลังเปลี่ยนเป็นพร้อมสรุป     |
| `demo.pr`                     | ประชาสัมพันธ์                               | ข่าวพร้อมเผยแพร่ 4 ข่าวและฉบับร่าง 2 ข่าว เปิด Preview และลองเผยแพร่บนฟีดภายใน |
| `demo.admin`                  | ผู้ดูแลระบบ                                 | ฝ่าย/งานประจำพนักงาน โครงสร้าง 30 งาน ประเภทงาน การเชื่อมต่อ และ audit         |

ยังมีบัญชีพนักงานสาธิตของอีก 8 ฝ่าย/กลุ่มงานในไฟล์บัญชี แต่ละคนสังกัด 1 ฝ่ายและ 1 งาน หัวหน้าฝ่ายมีขอบเขตกว้างเฉพาะชุดสาธิตเพื่อเปรียบเทียบการทำงานหลายฝ่าย

## ลองตามลำดับ

1. **ภาพรวม**: เข้า `demo.executive` ดู 9 รายการสาธิตพร้อมสรุปและ 3 รอตรวจในเดือนที่เพิ่มข้อมูล เปลี่ยนช่วงวันที่ให้ครอบคลุมเดือนก่อนจะเห็น 18 รายการสาธิตทั้งหมด (14 พร้อมสรุป / 4 รอตรวจ) ยอดจริงบนหน้ารวมรายการเดิมในระบบด้วย
2. **คลังข้อมูล**: ค้นคำว่า `[สาธิต]` เลือกฝ่าย ประเภท และสถานะ เปิดรายงานกิจกรรมขยับกายเพื่อดูตัวเลข 120 คน / 15 อาสาสมัคร / 3 จุดกิจกรรม และ PDF/ภาพประกอบ
3. **นำเข้า**: เข้า `demo.staff.health-promotion` เลือกไฟล์ตัวอย่างจาก `scripts/demo-assets/` → เลือกจัดข้อมูลเพื่อสรุปผลงาน → กรอกชื่อเรื่อง → จัดเก็บและตรวจข้อมูล ชื่อเรื่องจะแสดงต่อ ฝ่ายและงานถูกล็อกตามแอดมินกำหนด กรอกวันที่ พื้นที่ ผล และตัวเลขแล้วบันทึก
4. **หลักฐานรอเชื่อม**: ในหน้ารายงาน กดเชื่อมไฟล์ จะมีไฟล์สาธิตที่ยังไม่ผูกกับรายงานให้ลอง การฝากไฟล์เข้าคลังอย่างเดียวไม่เพิ่มจำนวนกิจกรรม
5. **รายงานจาก LINE**: มีข้อความจำลองรอเชื่อม 3 รายการ และอีก 2 รายการเชื่อมกับรายงานแล้ว รายการเหล่านี้สร้างในเครื่อง ไม่ใช่ผลทดสอบรับข้อมูลจาก LINE จริง พนักงานเลือกได้เฉพาะข้อความของตน หัวหน้าเลือกได้ตามขอบเขต
6. **ตรวจข้อมูล**: เข้า `demo.head` เลือกรายการรอตรวจ แก้ข้อมูล แล้วเปลี่ยนเป็นพร้อมสรุป ดูการเปลี่ยนยอดแดชบอร์ดและประวัติของรายการ
7. **ข่าว**: เข้า `demo.pr` เปิดข่าวร่าง ดู Preview และเผยแพร่ลงฟีดภายในได้ รูปข่าวมาจากหลักฐานรายงานต้นทาง ปุ่มส่ง LINE ต้องตั้งค่าบริการจริงก่อน ชุดสาธิตไม่ส่งข้อความออกนอกระบบและไม่จำลองสถานะส่งสำเร็จ
8. **ดูแลระบบ**: เข้า `demo.admin` แก้บัญชีสาธิต เลือกฝ่ายแล้วเลือก 1 งาน หรือตรวจข้อมูลตั้งต้น หลังแก้บัญชีเจ้าของบัญชีจะต้องเข้าสู่ระบบใหม่ ตรวจการเปลี่ยนแปลงได้ที่ประวัติการแก้ไข

## ขอบเขตที่ยังไม่เชื่อมบริการ

AI ยังไม่ได้ตั้งค่า จึงกรอก/ตรวจข้อมูลจากหลักฐานด้วยผู้ใช้ รายการ LINE เป็นข้อมูลจำลองเพื่อแสดงขั้นตอนภายในเท่านั้น การรับและส่ง LINE จริงยังต้องตั้งค่า channel, group และ HTTPS ตามคู่มือติดตั้ง

ไฟล์ PNG/PDF/Excel ใช้เปิดดูและดาวน์โหลดจริงได้ เอกสารแนบเป็นตัวอย่างเดือนตุลาคม 2569 ส่วนวันที่รายงานถูกตั้งให้มีข้อมูลในเดือนปัจจุบันและเดือนก่อน ณ วันที่เพิ่มชุดสาธิต
