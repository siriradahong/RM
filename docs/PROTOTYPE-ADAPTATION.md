รายงานที่เป็นหลักฐานของงานตรวจรับแล้วถูกล็อกการแก้ไขเนื้อหา หัวหน้าต้องเปิดโครงการ (ถ้าปิดแล้ว) และส่งงานกลับก่อน จึงแก้และยืนยันรายงานใหม่ แล้วส่งตรวจรับอีกครั้งได้ ไม่ใช่ระบบล็อกตามรอบเดือน

การเทียบรอบ: เดือนเทียบเดือนก่อน ไตรมาสเทียบไตรมาสก่อน ปีงบประมาณเทียบปีงบประมาณก่อน ช่วงกำหนดเองเทียบช่วงก่อนที่มีจำนวนวันเท่ากัน ไม่เติมยอดของเดือนที่เหลือด้วยการประมาณ ตัวเลขรอบปัจจุบันอาจยังเก็บไม่ครบเดือน จึงใช้ประกอบการอ่าน ไม่ใช่คะแนนประเมินบุคลากร

รายงานรอยืนยันที่ยังไม่มีวันที่กิจกรรมจัดเข้ารอบตามวันที่รับเข้าเพื่อให้ค้นตรวจได้ แต่ไม่รวมผลเชิงตัวเลข PDF พิมพ์รายการที่แสดงบนหน้าจอ (รวมตัวกรองย่อย) CSV ส่งออกทุกรายการในขอบเขต/รอบ/ฝ่าย/งาน/ประเภทที่เลือก พร้อมระบุสถานะ ไม่ส่งภาพประชาชนไปในไฟล์สรุป

## วิธีลองครบเส้นทาง

1. เข้าด้วยหัวหน้าที่แอดมินกำหนด scopes แล้ว → **โครงการและงานมอบหมาย** → **สร้างโครงการ** → เลือกฝ่ายและวันสิ้นสุด
2. **มอบหมายงาน** → เลือกเจ้าหน้าที่ในฝ่ายและกำหนดส่ง
3. เข้าด้วยเจ้าหน้าที่คนนั้น → เมนูเดียวกัน → **เริ่มงาน** → **เขียนรายงาน** (นำชื่องานมาให้ในช่องข้อความ)
4. ส่งข้อความ/แนบไฟล์ตามเดิม ตรวจแก้ข้อมูลจริง แล้ว **ยืนยันข้อมูลเพื่อสรุป**
5. กลับงานมอบหมาย → **ส่งรายงานให้หัวหน้า** → ค้น/เลือกรายงานที่ยืนยัน → **ยืนยันส่งรายงาน**
6. หัวหน้าเปิดรายงานหลักฐาน → **ตรวจรับงาน** หรือ **ส่งกลับแก้ไข** พร้อมเหตุผล → เปลี่ยนสถานะโครงการเป็น **เสร็จสิ้น** เมื่อทุกงานครบ
7. เปิด **สรุปผลงาน** เลือกเดือน/ไตรมาส/ปี กดฝ่าย/ประเภทเพื่อดูต้นทาง ดาวน์โหลด CSV หรือพิมพ์/บันทึก PDF

รายงานที่ตนนำเข้าไม่ได้แปลว่าเป็นผลงานส่วนตัวทั้งหมด ระบบแสดงผู้ส่งและผู้ปฏิบัติงานตามต้นฉบับแยกกัน การให้เครดิตบุคลากรร่วมงานแบบมีรหัสบุคคลยังต้องออกแบบเพิ่มเติมก่อนใช้ประเมินบุคคลจริง

## สิ่งที่มีอยู่เดิมและยังคงใช้

- 5 บทบาท บัญชีหลายบทบาทได้ แอดมินจัดฝ่าย/งาน เปิด–ปิดบัญชี
- โครงสร้างส่วน → ฝ่าย/กลุ่มงาน → งาน/ศูนย์ และประเภทงานที่เพิ่มได้
- เพิ่มข้อมูลแบบข้อความช่องเดียวพร้อมไฟล์ หรือเก็บไว้ค้นหาโดยไม่รวมยอด
- หน้าตรวจข้อมูลกระชับ แก้เฉพาะจุดและยืนยันก่อนสรุป
- LINE webhook รับข้อมูลเมื่อกำหนดค่าจริง, ข่าวผ่าน PR และส่ง LINE ด้วยคำสั่งที่ชัดเจน
- รายงานเก่าคงสังกัดที่บันทึกไว้เมื่อย้ายเจ้าหน้าที่
